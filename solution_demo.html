AI-assisted code-generation for image data analysis#

bia_bob is a Python library that connects Jupyter with large language models (LLM) and custom bio-image analysis instructions.

When using bia-bob to prompt LLMs, the prompts you enter including existing variable names etc. are sent to the LLM provider. If you are using commercial cloud providers, where it is not obvious, what they are doing with data you send there, do not submit any sensitive, secret or private information. Also check bia-bob’s code recommendations before executing them.

Also LLMs make mistakes. Review code carefully.

First we initialize the AI-assistant to make use of the Helmholtz blablador infrastructure.

from bia_bob import config_blablador, bob

config_blablador()

Prompting#

You can prompt for a single short task using %bob.

%bob print hello world.

Print the text Hello World to the console.

print("Hello World")

Hello World

More advanced multi-line tasks can be prompted using %%bob.

%%bob 
load data/blobs.tif and show it
This notebook may contain text, code and images generated by artificial intelligence. Used model: alias-code, vision model: alias-code, fast_model: alias-fast, endpoint: https://api.blablador.fz-juelich.de/v1/, bia-bob version: 0.37.1.. Do not enter sensitive or private information and verify generated contents according to good scientific practice. Read more: https://github.com/haesleinhuepf/bia-bob#disclaimer

I will load data/blobs.tif and display it interactively using StackView.

from skimage.io import imread
import stackview

image = imread("data/blobs.tif")

Exercise#

Ask Bob to plot a sigmoid curve.

%%bob
plot a sigmoid
This notebook may contain text, code and images generated by artificial intelligence. Used model: claude-sonnet-5, vision model: claude-sonnet-5, fast_model: None, endpoint: None, bia-bob version: 0.37.1.. Do not enter sensitive or private information and verify generated contents according to good scientific practice. Read more: https://github.com/haesleinhuepf/bia-bob#disclaimer

Plot a sigmoid function using numpy and matplotlib.

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-10, 10, 200)
y = 1 / (1 + np.exp(-x))

plt.figure(figsize=(6, 4))
plt.plot(x, y)
plt.xlabel("x")
plt.ylabel("sigmoid(x)")
plt.title("Sigmoid Function")
plt.grid(True)
plt.show()
